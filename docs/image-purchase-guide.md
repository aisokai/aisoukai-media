# 画像追加購入ガイド

---

## ⚡ 購入後チェックリスト（Pixta 購入済み → 記事公開まで）

画像を Pixta で購入したら、以下の順番で作業する:

```
1. Pixta からダウンロードし、ファイルを保存する
   → public/images/library/inbox/ に配置

2. インポート確認（dry-run）
   npm run image:import-inbox -- --dry-run

3. インポート実行
   npm run image:import-inbox -- --apply

4. ライブラリ一覧を確認
   npm run image:list

5. カテゴリを整理する（general が残っている場合）
   npm run image:reclassify

6. ライセンス情報を入力する（購入日・プランを記入）
   npm run image:license:bulk-template   # → docs/license-bulk-template.md を確認し purchase_date と plan を埋める
   npm run image:license:update -- <image-id> --date YYYY-MM-DD --plan "シングルパック"

7. 画像候補を確認する
   npm run image:suggest -- <slug>

8. 記事に割り当てる
   npm run image:assign -- <slug> --image <image-id>

9. 整合性チェック
   npm run image:check

10. ビルド確認
    npm run build
```

> ライセンス情報を一括確認したい場合は `npm run image:license:bulk-template` を先に実行すると、
> 全 TODO 画像を Markdown テーブルで確認できます（`docs/license-bulk-template.md` に出力）。

## root-canal（根管治療）

### 必要な画像タイプ

- 歯の断面イラスト（神経・歯髄が描かれたもの）
- ファイル（根管用器具）を使った治療イメージ
- リーマーやリファイル等の器具写真
- 痛みの少ない治療を受けている患者イメージ
- 「ラバーダム」を使った処置風景（あれば差別化になる）

### 避けるべき画像

- 抜歯後の出血・血液が鮮明に写っているもの
- 患者が明らかに苦痛の表情をしているもの
- 「神経を抜く」を視覚的に強調した過激な表現

### 推奨検索キーワード（Pixta）

```
根管治療　歯の神経　歯髄炎　ファイル 歯科
歯科 断面 神経 イラスト
歯科治療 ラバーダム
```

### 医療広告上の注意点

- 「痛くない根管治療」などの断定表現は避ける
- 「〇回で完了」など回数保証を示す画像テキストは不可
- 治療前後の比較写真は患者同意書が必要（素材写真でも注釈を確認）

### 目標購入枚数

最低 3 枚（器具写真・断面イラスト・治療シーンの組み合わせ）

## periodontal（歯周病）

### 必要な画像タイプ

- 歯肉炎・歯周炎を示す口腔内写真（素材）またはイラスト
- スケーリング・PMTC 等の処置イメージ
- 「歯ぐきが赤い」「腫れている」状態を示すイラスト
- 生活習慣（喫煙・食事）と歯周病の関連を示す概念図
- ブラッシング指導の様子

### 避けるべき画像

- 実際の患者の化膿・重度歯周炎を強調した不快な写真
- 「歯が抜ける」「骨が溶ける」を過激に描いたビジュアル

### 推奨検索キーワード（Pixta）

```
歯周病　歯ぐき　歯肉炎　スケーリング
歯周病 イラスト　歯ぐき 腫れ
歯周病 原因　生活習慣 歯科
```

### 医療広告上の注意点

- 「歯周病が完治する」「骨が再生する」等の断定は不可
- 治療前後比較は患者同意・記載義務あり（素材選択で避けるのが安全）
- 歯周病と全身疾患（糖尿病・心疾患）の関連は「リスクがある」表現に留める

### 目標購入枚数

最低 3 枚（イラスト・スケーリング・ブラッシング指導の組み合わせ）

## wisdom-tooth（親知らず）

### 必要な画像タイプ

- パノラマX線 or 口腔内の親知らず写真（素材・イラスト）
- 抜歯前の診察・説明シーン
- 横向き（水平埋伏）親知らずのイラスト断面図
- 術後ケア（ガーゼ・アイスパック）のイメージ

### 避けるべき画像

- 実際の抜歯中の出血・抜いた歯の写真（嫌悪感を与えるもの）
- 痛みで泣いているような極端な表情

### 推奨検索キーワード（Pixta）

```
親知らず　抜歯　歯科　水平埋伏
口腔外科　親知らず 説明
親知らず X線　パノラマ
```

### 医療広告上の注意点

- 「必ず抜く必要がある」「抜いた方がいい」等の断定を含む画像テキストは使用不可
- 実際の患者口腔内写真を使う場合は患者同意書が必要（Pixta 素材は不要）
- 術後リスク（麻痺・ドライソケット）に関する記述は記事本文側でコントロールする

### 目標購入枚数

最低 3 枚（X線イラスト・説明シーン・ケア画像の組み合わせ）

## 購入手順

1. Pixta（https://pixta.jp）にログインして素材を検索
2. 素材ダウンロード後に `public/images/library/inbox/` に保存
3. `npm run image:import-inbox` でライブラリに取り込む（dry-run で確認後 `--apply`）
4. `data/image-library.json` の `license_note` を更新する（後述）
5. `npm run image:check` でエラーがないことを確認する

## license_note の記入方法

購入後に `data/image-library.json` の対象エントリを開き、以下の形式で更新する:

```json
"license_note": "Pixta ID: XXXXXXX — 購入日: 2026-05-13 / プラン: シングルパック"
```

プラン種別の例:
- シングルパック
- 定額プラン（月 XX 点）
- 法人プラン

`npm run image:check` を実行して警告が解消されることを確認する。
