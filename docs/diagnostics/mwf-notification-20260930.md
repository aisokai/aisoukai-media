# 2026-09-30 通知の改善

## 変更

対象日の記事作成結果、先生によるテーマ確認、運用側の技術確認、重複・予定日前の見送りを分けました。採用記録が見つからない場合は未採用と断定せず、該当テーマの編集画面と保存操作を案内します。重複回避・予定日前には操作を求めません。

通知に使う候補情報はID・100文字までの安全なタイトル・理由区分だけです。notes・本文・例外内容は含めず、保護対象候補のタイトルは非表示にします。固定管理画面URL、表示件数上限、3800文字上限を設けています。

同じ対象枠の生成日時と状態を要約し、作成済みや結果不明の記事がある場合は「新規記事は作成していません」と断定しません。管理画面のID絞り込みは完全一致で、80件制限より先に適用し、不正IDでは全件表示しません。未ログイン時も有効なIDの固定管理画面への復帰先を保持します。

生成・審査・公開・採用操作の権限、通知の1枠1回と送信結果不明時の再送禁止は変更していません。

## 通知文の例

Managerが提示した非機密のテーマ名と状態を使ったローカル整形例です。実送信はしていません。例の作成件数は対象枠に記事がない合成条件です。

```text
ブログ記事の作成結果（2026-09-30）
対象日分の新規記事は作成していません。

先生に確認をお願いしたいテーマ：1件

https://aisoukai-media.vercel.app/admin/article-topics?id=TOPIC-20260512-032

重複を避けて見送り：1件（操作不要）

予定日前のため待機：11件（操作不要。予定日以降の対象になります）
```
