# 記事スキーマ仕様書

最終更新: 2026-05-11

---

## frontmatter 仕様

```yaml
---
title: "記事タイトル（必須）"
date: "YYYY-MM-DD（必須）"
excerpt: "SEO用説明文（必須）"
category: "カテゴリ名（必須）"
tags:
  - タグ1
  - タグ2
image: "/images/posts/slug.jpg（省略可）"
---
```

### 各フィールドのルール

| フィールド | 必須 | 型 | 制約 |
|-----------|------|-----|------|
| `title` | ✅ | string | 20〜40文字推奨。「〜について」「〜とは」「〜を解説」などの語尾パターンを使う |
| `date` | ✅ | string | `"YYYY-MM-DD"` 形式（ダブルクォート必須）。将来日付可（予約投稿として扱う） |
| `excerpt` | ✅ | string | 60〜120文字。疑問形または「〜について紹介します」で締める。断定的な医療効果表現禁止 |
| `description` | 互換 | string | 旧 frontmatter 互換。新規作成では `excerpt` を使用する |
| `category` | ✅ | string | 後述のカテゴリ一覧から1つ選択。一覧外は使用禁止 |
| `tags` | ✅ | string[] | 2〜4件。カテゴリ名の繰り返しは不要。具体的なキーワードを選ぶ |
| `image` | ❌ | string | `/images/posts/` 配下のパス。省略時はカテゴリグラデーション+アイコンを自動適用 |

## slug 命名ルール

**形式:** `YYYY-MM-DD-{topic-keyword}.md`

### ルール

1. **日付プレフィックス必須** — `getAllPosts()` は日付降順ソートのため、ファイル名の日付と frontmatter の date を一致させる
2. **トピックキーワード** — 英語または日本語ローマ字。ハイフン区切り。小文字のみ
3. **一意性** — 同日・同トピックは `-2`, `-3` などのサフィックスを付ける
4. **長さ** — `{topic-keyword}` 部分は 3〜30文字

### 命名例

| 記事テーマ | slug |
|-----------|------|
| インプラント費用 | `2026-05-15-implant-cost.md` |
| 親知らず抜歯後ケア | `2026-05-20-wisdom-tooth-aftercare.md` |
| 子どものフッ素 | `2026-06-01-fluoride-for-kids.md` |
| 歯周病と全身疾患 | `2026-06-10-periodontal-systemic.md` |

### NG パターン

- `article-1.md` — 日付なし・意味不明
- `2026-05-11-虫歯.md` — 日本語文字（URLエンコードの問題）
- `2026-05-11-cavity-treatment.md` — 既存スラグと衝突（`2026-01-20-cavity-treatment.md` が存在）

## tags ルール

### 目的

- 同一カテゴリ内の細分類
- 将来的な関連記事表示の基礎データ

### 選定ルール

1. **2〜4件**（少なすぎても多すぎても検索性が下がる）
2. **カテゴリ名の単純繰り返しは避ける** — `category: "虫歯治療"` で `tags: [虫歯治療]` は不要
3. **具体的なキーワードを使う** — 「歯科」「治療」などの汎用語より「フッ素」「シーラント」「神経」など
4. **日本語で統一**（英語混在しない）

### カテゴリ別 tags 参考例

| カテゴリ | 推奨 tags の例 |
|---------|---------------|

| 根管治療 | 神経, 根管, 抜歯回避, 再根管 |
| 歯周病治療 | 歯周病, 歯石, スケーリング, 歯肉炎 |

## description SEO ルール

### 文字数

- **最低 60文字・推奨 80〜120文字**（Google のスニペット表示上限は約160文字）

### パターン

疑問喚起型（検索意図に合わせる）:
```
「〜が気になる方へ」「〜をご存知でしょうか」
```

解説型:
```
「〜の原因・症状・治療法をわかりやすく解説します。」
```

NG 表現:
```
× 「必ず治ります」
× 「完全に予防できます」
× 「最高の治療法です」
× 「保証します」
```

OK 表現:
```
○ 「〜に有効とされています」
○ 「〜の可能性があります」
○ 「〜について解説します」
○ 「〜を目指した取り組みを紹介します」
```

## 重複記事防止チェックリスト

記事追加前に以下を確認する:

```bash
# 同じスラグが存在しないか
ls content/posts/ | grep "topic-keyword"

# 同テーマの記事がないか（タイトルキーワードで確認）
grep -r "キーワード" content/posts/ --include="*.md" -l
```
