# 2026年 ホームホワイトニングキャンペーン LP 設計メモ

## 目的

- `aisoukai-media` に患者向けキャンペーン LP を 1 ページ追加する
- チラシ画像に依存せず、Web で読みやすい本文中心の構成にする
- スマホ閲覧を最優先にしつつ、既存サイトの共通ヘッダー・フッターに自然に接続する
- 医療広告として過度な表現を避け、価格・期間・注意事項を明示する

## 対象 URL

- `/campaign/home-whitening-2026`

## 採用方針

- `src/app/campaign/home-whitening-2026/page.tsx` を新規追加する
- 既存の `Header` / `Footer` / `seo.ts` を流用し、運用ロジックやブログ機能には触れない
- CTA は暫定で `/contact` に統一する
- チラシ画像は repo 内未確認のため、画像なしでも成立する本文中心 LP を優先する
- 後から画像を差し込みやすいよう、補助ビジュアル領域を追加しやすいレイアウトにする

## 情報設計

1. Hero
2. キャンペーン内容比較
3. おすすめ対象
4. ホームホワイトニング説明
5. 当院で行うメリット
6. ご利用の流れ
7. 注意事項
8. 最終 CTA

## 表現上の制約

- 「自然な白さを目指す」などの表現に留め、効果保証はしない
- Before/After 訴求は入れない
- 「効果には個人差があります」を明記する
- 税込価格とキャンペーン期間を明記する
- CTA が仮リンクであることを最終報告で明示する

## 影響範囲

- 追加: `src/app/campaign/home-whitening-2026/page.tsx`
- 変更候補: `src/app/sitemap.ts`
- 変更しない: ブログ公開判定、記事運用スクリプト、管理画面、画像運用 JSON
